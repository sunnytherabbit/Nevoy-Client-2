# File cleanup policy

When cleaning up unneeded or trash files in this workspace, never use `rm` or any irreversible deletion. Always move items to `/Users/tl/Desktop/MCBE/Clients/temp_bin` (preferably under a dated subdirectory) so they remain reversible. Preserve the relative directory structure when moving to avoid name collisions.

This policy applies to:

- Old decompilation files
- macOS `.DS_Store` files
- Broken or outdated tooling
- Stale logs
- Any other unneeded workspace artifacts
