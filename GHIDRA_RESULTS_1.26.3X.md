## How to read the output

- Each function is introduced by a `// Function:` comment.
- `func_0x1800xxxxxx` are function names.
- `DAT_1800xxxxxx` and `PTR_1800xxxxxx` are global data and pointers.
- `local_`/`uVar`/`iVar`/`lVar` etc. are stack and local variables generated by Ghidra.

## Caveats

- This is **decompilation pseudo-C**, not the original source.
- It cannot be recompiled back into the exact original DLL.
- As with any stripped C++ binary, many names are inferred and the control flow is approximated.
