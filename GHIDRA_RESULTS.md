## How to read the output

- Each function is introduced by a `// Function:` comment.
- `FUN_1800xxxxxx` / `func_0x1800xxxxxx_*` are function names.
- `DAT_1800xxxxxx` and `PTR_1800xxxxxx` are global data and pointers in `.rdata`/`.data`.
- `_local_` variables are stack locals.
- `uVar`, `iVar`, `pvVar`, `pcVar`, etc., are typed local names generated by Ghidra.

## Key observations from Ghidra

- The binary uses standard MSVC x64 PE exception handling (`.pdata`) and RTTI.
- Ghidra identified more functions than the previous RetDec pass and recovered better type names for many globals.
- The decompilation quality is similar to RetDec but with Ghidra's naming conventions and data-type recovery.
- As with the RetDec output, this is **pseudo-C** and cannot be recompiled into the original DLL.
